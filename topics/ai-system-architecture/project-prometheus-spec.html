Project Prometheus —— 总规范 v1.0 ​

2026-07-03 · 导演 × 演员 联合制定 这是论文、专利、代码、书的唯一理论来源。所有产出必须与本文一致。

一、项目定位 ​

不是改进 Transformer，是定义一种新的计算方式。

维度TransformerField Computation

二、核心公理（Axioms） ​

Axiom 1（语义）：Meaning is not a vector. Meaning is an equivalence class of field configurations. 意义 = 拓扑等价类，由拓扑不变量 I(ϕ) 定义。

Axiom 2（智能）：Intelligence is stabilization, not prediction. 理解 = 场收敛到稳定吸引子。推理 = 相变——系统跨越能垒后的拓扑跃迁。

Axiom 3（语言）：Language is a boundary condition, not an internal representation. 文本是场的边界条件（输入激励 J(x)）和投影（输出解码），不是内部状态。

Axiom 4（推理）：Reasoning is topological evolution, not symbolic manipulation. 推理不是搜索，而是场在约束下的连续演化，直到达到新的稳定拓扑。

Axiom 5（记忆）：Memory is persistent field deformation, not cached activation. 记忆 = 慢变量 m(x,t) 对场的持续形变。

Axiom 6（规范不变性）：Meaning is preserved under gauge transformations that leave topological invariants unchanged. 规范群 G 是推论，不是定义——先定义 I，再导出 G。

三、数学定义 ​

3.1 语义流形 ​

M⊂Rd,d=64

基础拓扑固定（Rd），度量张量 gij(x;θ) 可学习。

3.2 语义场 ​

ϕ:M→Rk,k=32

k 维语义通道（实体、动作、时间、情绪、逻辑、价值、因果……）。不是标量场，是张量场。

3.3 输入编码 ​

J(x)=∑iaiexp⁡(−|x−μi|g22σi2)

初始条件：ϕ(x,0)=J(x)

3.4 演化方程 ​

∂ϕ∂t=∇g⋅(D(x)∇gϕ)+F(ϕ)+J(x)
  • D(x)：非均匀扩散张量（由语义度量决定）
  • F(ϕ)=W1ϕ+W2ϕ2−W3ϕ3：非线性反应项
  • ∇g：度量 g 下的协变导数

3.5 能量泛函 ​

E[ϕ]=∫M(|∇gϕ|2+V(ϕ))|g|dxV(ϕ)=(ϕ2−1)2（双阱势）

梯度流：∂ϕ∂t=−δEδϕ

3.6 记忆 ​

∂m∂t=αϕ−βm

推理时：ϕ←ϕ+m

3.7 规范不变性 ​

Meaning(ϕ)=I(ϕ)

I 是拓扑不变量函数（持续同调图、Betti 数）。

G={g∈Diff(M):I(g⋅ϕ)=I(ϕ),∀ϕ}

3.8 输出 ​

轨迹：γ˙=−∇gϕ

输出：y(t)=R(ϕ(γ(t)))，R 是轻量 Transformer 解码器（交叉注意力 + 自回归）。

3.9 训练损失 ​

L=LE+λ1LT+λ2LG
  • LE=E(ϕtrue)−E(ϕfalse)：能量损失
  • LT=dWasserstein(PD(ϕ1),PD(ϕ2))：拓扑损失
  • LG=|R(ϕ)−R(g(ϕ))|：规范损失

四、关键设计决策 ​

决策选择理由
场类型张量场（Rk，k=32）标量场无法表达逻辑关系
流形固定 Rd + 可学习度量保证连通性，度量学习成熟
扩散非均匀 D(x)，由度量决定语义距离 ≠ 欧氏距离
势能双阱势 (ϕ2−1)2天然产生稳定吸引子
规范群不定义 G，定义 I绕过循环定义
解码器轻量 Transformer流畅性由架构保证，不重复造轮子
PDE 求解谱方法 + 神经算子O(Nd)→O(K) 降维
名称Attractor Semantic Field (ASF)或 Field Computation，放弃 TFM 命名
