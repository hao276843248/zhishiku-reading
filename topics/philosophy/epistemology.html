认识论与科学哲学：知识的边界 ​

我们能知道什么？知识从何而来？科学为什么可靠？这些追问构成哲学中最"烧脑"却也最实用的领域——认识论（Epistemology）和科学哲学（Philosophy of Science）。它们不仅是学术问题，更是每个人每天都在面对的：如何判断一条消息的真假？如何建立可信的判断？

整理日期：2026-06-17

一、什么是知识 ​

1.1 知识的经典定义：柏拉图三元组 ​

柏拉图（约公元前428-前348）提出知识的经典定义：

知识 = 信念（Belief）+ 证据（Justification）+ 证真（Truth）

三者缺一不可：
✗ 信念但不证真 → "我相信地球是平的"，但这是错的 → 不是知识
✗ 有证据但不信念 → "科学家证明地球是圆的"，但我不信 → 不是知识
✓ 三者齐备 → 相信地球是圆的，且有科学证据，且地球确实是圆的 → 知识

1.2 知识的来源问题 ​

知识从哪里来？

理性主义：知识来自理性/先天观念
  代表：柏拉图、笛卡尔、康德
  例：数学真理 = 理性推导，不需要经验

经验主义：知识来自感官经验
  代表：亚里士多德、休谟、洛克
  例：科学真理 = 观察实验归纳

辩证唯物主义：知识来自实践
  代表：马克思、毛泽东
  例：认识从实践中来，到实践中去
  参见：[毛泽东哲学《实践论》](../mao-zedong/mao-philosophy-practice-contradiction.md)

二、可知论 vs 怀疑论 ​

2.1 核心对立 ​

立场主张代表人物
可知论我们能够认识世界的真实面貌大多数哲学家
怀疑论我们的认识能力有限，无法获得确定知识皮浪、休谟、笛卡尔（方法论怀疑）

2.2 怀疑论的核心挑战 ​

休谟的怀疑论三连：

  1. 归纳问题：

    太阳过去每天升起 → 太阳明天会升起？ 这是归纳推理，但归纳本身无法被证明。 逻辑上，太阳明天可能不升起！

  2. 因果难题：

    我们看到的只是"先后发生"，不是"因果关系"。 雨伞撑开 + 雨停了 ≠ 雨伞导致雨停（只是同时发生） 因果只是心理习惯，不是逻辑必然。

  3. 外部世界存在吗？

    可能是梦境——你无法证明此刻不是梦。 （"缸中之脑"思想实验）

2.3 笛卡尔的回应：方法论怀疑 ​

笛卡尔的策略： 怀疑一切，看什么无法被怀疑。

怀疑一切：
- 感官可能欺骗我 → 怀疑感官
- 数学可能有人让我出错 → 怀疑数学
- 可能我只是一直在做梦 → 怀疑现实

唯一无法怀疑的：
- "我在怀疑"这件事本身
- 即："我思故我在"（Cogito ergo sum）

虽然我可能一切都是假的，但"我正在思考"这件事本身是真的。 这是认识的阿基米德点。

2.4 辩证唯物论的回应 ​

马克思、恩格斯的立场：

怀疑论的贡献：指出认识的相对性
辩证唯物论的回应：
  - 承认认识的相对性，但不陷入虚无主义
  - 真理是不断接近的过程
  - 实践是检验真理的唯一标准

毛泽东《实践论》深化了这一观点：认识的相对性不等于"什么都不能知道"，而是认识是一个不断发展深化的过程。参见：毛泽东哲学：实践论

三、科学哲学：科学为什么可靠 ​

3.1 波普尔：可证伪性 ​

卡尔·波普尔（1902-1994）提出科学最重要的特征：可证伪性（Falsifiability）。

核心思想：

科学理论必须能够被反驳/证伪

可证伪 ≠ 会错
可证伪 = 存在一种可能的情况，如果发生，理论就被推翻

可证伪的例子：
- "所有天鹅都是白的" → 发现一只黑天鹅 → 被证伪 ✓
- "地球是圆的" → 可以设计实验验证，也可以被推翻 ✓
- "明天的股市会涨或跌" → 两种可能都算对 → 不可证伪 ✗

伪科学的特征：

  • 无法被证伪（总是能自圆其说）
  • 拒绝接受反驳证据
  • 使用模糊语言避免被检验

3.2 库恩：范式转换 ​

托马斯·库恩（1922-1996）的《科学革命的结构》改变了我们对科学发展的理解。

范式（Paradigm）：

范式 = 某一时期科学共同体共同接受的理论框架、方法、问题域

常规科学：
  在范式内解题（"解谜"）
  ↓ 遇到无法解释的异常
  危机
  ↓ 出现新的竞争框架
  革命
  ↓ 新范式取代旧范式
  新的常规科学开始...

历史上的范式转换：

旧范式新范式革命标志
地心说日心说哥白尼
牛顿力学相对论爱因斯坦
经典物理量子物理普朗克

3.3 拉卡托斯：研究纲领 ​

伊姆雷·拉卡托斯（1922-1974）发展了更精细的科学评价框架。

研究纲领（Research Programme）：

一个科学研究纲领包含：
- 硬核（Hard Core）：不可反驳的核心假设
  例：牛顿力学的核心——力是物体运动的原因
- 保护带（Protective Belt）：可调整的辅助假设
  例：摩擦力、空气阻力等

当异常出现时，先调整保护带
只有硬核被证伪时，才放弃整个纲领

四、批判性思维：如何判断信息真伪 ​

4.1 认知偏差清单 ​

每个人都会犯的思维错误：

偏差含义例子
确认偏误只看到支持自己观点的证据认为中医有效，只记住治好的案例
可得性启发以为常见的事更可能发生飞机失事很少，但感觉很常见
后见之明事后觉得"早就知道会这样"事后诸葛亮
锚定效应被第一印象影响判断谈判时先开口的人占优势
过度自信高估自己判断的准确度90%的司机认为自己的驾驶技术高于平均水平

4.2 逻辑谬误清单 ​

常见论证错误：

谬误含义例子
诉诸权威"专家说的，所以是对的"权威也可能错，需要看论证
诉诸情感用情感代替论证"你不支持就是冷血"
人身攻击攻击人，不攻击论点"他品格有问题，所以观点错"
稻草人曲解对方论点再反驳"你说要自由，就是说可以杀人？"
滑坡不给底线，一路下滑"今天允许A，明天就允许B，后天就是世界末日"
循环论证用结论证明前提"上帝存在，因为圣经说的；圣经可信，因为上帝写的"

4.3 批判性思维的操作步骤 ​

面对任何观点，用这个流程检验：

第一步：这是什么观点？
  - 用一句话复述对方观点
  - 确认自己理解正确

第二步：证据是什么？
  - 谁说的？可靠吗？
  - 样本够大吗？控制变量了吗？
  - 来源是什么？有没有利益关联？

第三步：推理有效吗？
  - 从证据到结论，逻辑通顺吗？
  - 有没有逻辑跳跃？
  - 有没有其他解释？

第四步：有没有反驳？
  - 反面证据是什么？
  - 有人做过反驳吗？
  - 我的结论是否过于绝对？

第五步：我的立场是什么？
  - 在相信与不相信之间，我如何取舍？
  - 我愿意多大程度地相信？
  - 需要什么新证据可以改变我的立场？

五、认识论的现实应用 ​

5.1 如何判断新闻真假 ​

假新闻识别清单：

1. 来源检查
   - 这个媒体/账号可靠吗？
   - 有没有其他可靠来源确认？

2. 内容检查
   - 图片是PS的吗？视频是什么时候的？
   - 数据有没有上下文？
   - 是观点还是事实？

3. 动机检查
   - 发布者有什么目的？
   - 煽动情绪还是提供信息？

4. 逻辑检查
   - 论证符合逻辑吗？
   - 符合常识吗？

5.2 如何建立可信判断 ​

判断的可信度分层：

高可信度（可直接接受）：
  ✓ 多方独立来源一致确认
  ✓ 有原始数据/一手证据
  ✓ 符合已知事实框架

中等可信度（审慎接受）：
  ~ 单个权威来源
  ~ 符合直觉但未经充分验证
  ~ 有反例但比例小

低可信度（保留怀疑）：
  ✗ 来源单一，无法核实
  ✗ 与已知事实框架矛盾
  ✗ 动机可疑

5.3 投资决策中的认识论 ​

投资判断的错误模式：

确认偏误：
  只看利好消息，忽视利空信号

后见之明：
  后悔"早知道"——其实是无法预测的

过度自信：
  "我知道这只股票会涨"——实际上无法确定

锚定效应：
  死死盯住买入价，不愿止损

六、知识论的核心原则 ​

认识论总结（六条原则）：

1. 知识需要证据支持
   → 没有证据的信念不是知识

2. 证据需要可检验
   → 不可检验的主张无法判断真假

3. 知识是开放的
   → 任何知识都可能被修正

4. 实践是检验的标准
   → 思想的效果需要在行动中验证

5. 承认不确定性
   → 不确定不等于不知道

6. 持续追问
   → 苏格拉底式追问是最好的思维习惯

七、与毛泽东哲学的呼应 ​

毛泽东《实践论》的认识论框架与波普尔的证伪主义有有趣的对话空间。

维度波普尔（证伪主义）毛泽东（实践论）
理论地位猜想，迟早被证伪理性认识，来源于实践
检验标准可证伪性 + 暂时未被证伪实践检验
科学发展范式革命，猜想→反驳→新猜想实践→认识→再实践
共同点都强调知识的可错性和开放性
